About the project

CineMatch.
Powered by data. Made for movie lovers.

CineMatch is a Big Data Analytics project that explores how movie metadata, user ratings and genre information can make film discovery more useful. It combines a live catalogue of Indian cinema with a local recommendation engine, giving viewers one place to discover films across languages.

The project demonstrates a practical data pipeline: prepare and validate movie-rating data, analyse genre and rating patterns, calculate recommendation scores, and present results through a responsive web application. Live catalogue metadata and posters are supplied by TMDB; the recommendation experiment uses the MovieLens dataset.

🇮🇳 Indian-first discoveryExplore Indian-origin films across languages, with search and filters.
📊 Data preparationClean, transform and validate movie and rating records.
✦ Hybrid recommendationsPopularity ranking, TF-IDF content similarity and item-item collaborative filtering.
🔎 Explainable resultsUse ratings, genres and similarity signals to help explore new titles.
